成就

你的设备必须支持 Game Center。例如，iPhone 3G 不支持。

虽然《龙之隘口之王》的基本目标是王者胜利，但还有许多其他目标。成就提供了一种追踪（以及与朋友分享）这些目标的方式。要启用成就，你必须登录 Game Center。你可以在游戏开始时进行此操作，或在启动《龙之隘口之王》前使用 Game Center 应用。

成就包括收集众多宝物、不仅作为国王还作为女王获胜，或者探索地图的每一寸角落。有些（例如成为龙之隘口女王）是零和一的。对于其他成就，你可以看到自己的进度。

当你获得成就时，屏幕会显示简短提示。你可以通过点击控制界面中的奖杯按钮，或在 Game Center 应用中查看你的成就。（你需要连接互联网。）

请注意，并非所有可能的成就都会被列出。完成一些成就可能会揭示新的成就，而另一些则会因故事事件而获得。

开始新游戏不会重置你的成就——毕竟，你可能既想作为女王获胜又想作为国王获胜。如果你想重新开始，可以从控制界面清除所有成就。每个玩家都有自己的成就，因此你也可以使用 Game Center 应用退出登录，然后以不同玩家的身份登录。
